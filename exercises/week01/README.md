# Week 1 — Day 1 exercises

Rules: no AI-written code, no copying. Docs (javascript.info, MDN) are allowed.
Create one file per exercise (`01-fizzbuzz.js`, etc.) and run each with `node 01-fizzbuzz.js`.
Commit after each exercise that works.

1. **FizzBuzz.** Print the numbers 1–100. For multiples of 3 print `Fizz`, for multiples of 5 print `Buzz`, and for multiples of both print `FizzBuzz`.
   - *Think:* why does the order of your `if` checks matter?
2. **Reverse a string.** Write `reverse("hello")` → `"olleh"`. Do it twice: once with a loop and once with built-in methods.
   - *Think:* which version is easier to read? Which would you write at work?
3. **Count vowels.** `countVowels("Programming is fun")` → `5`. Upper and lower case must both count.
4. **Largest number.** `largest([3, 9, 2, 7])` → `9`. **Don't use `Math.max`.**
   - *Think:* what should `largest([])` return? Decide and justify it.
5. **Palindrome.** `isPalindrome("A man, a plan, a canal: Panama")` → `true`. Ignore case, spaces and punctuation.

When you're done, ask Claude to review them. Expect tough feedback; that's how you learn.

**Stretch:** `wordFrequency("the cat and the hat")` → `{ the: 2, cat: 1, and: 1, hat: 1 }`
